문의 전에 확인할 사항

  1. KSRRangAudio를 최신 버전으로 업데이트합니다.
  2. 앱을 완전히 종료한 뒤 다시 실행합니다.
  3. 기기의 저장 공간과 네트워크 연결 상태를 확인합니다.
  4. Android 설정에서 필요한 미디어·마이크·알림 권한을 확인합니다.
  5. 원격 서버를 사용하는 경우 다른 앱이나 PC에서도 접속 가능한지 확인합니다.
원본 파일 보관 권장 편집, 보컬 제거 또는 오버더빙 작업을 시작하기 전에 중요한 원본 파일은 별도의 위치에 백업하는 것을 권장합니다.

재생 문제 해결

로컬 또는 원격 오디오·동영상 파일이 열리지 않거나 재생이 끊길 때 다음 항목을 순서대로 확인하세요.

  1. 같은 파일이 다른 플레이어에서 정상 재생되는지 확인합니다.
  2. 파일이 완전히 복사되었고 손상되지 않았는지 확인합니다.
  3. Android 설정에서 KSRRangAudio의 오디오·동영상 접근 권한을 확인합니다.
  4. 외장 저장장치 또는 파일 제공 앱에서 선택한 파일은 다시 선택해 봅니다.
  5. 원격 파일이면 Wi-Fi 신호와 서버 응답 상태를 확인합니다.
  6. 고해상도 또는 높은 비트레이트 파일은 다른 앱을 종료한 뒤 재생합니다.
지원 형식 관련 파일 확장자가 같아도 내부 코덱이 다를 수 있습니다. 특정 파일만 재생되지 않으면 문의 시 파일 확장자, 오디오·비디오 코덱, 파일 크기를 알려 주세요.

SMB·FTP·SFTP 연결 문제 해결

먼저 서버 주소, 포트, 계정정보와 네트워크 연결 상태를 확인하세요. 비밀번호나 개인키는 고객지원 이메일로 보내지 마세요.

공통 확인 항목

  • 휴대전화에서 서버 주소로 접근 가능한 네트워크인지 확인합니다.
  • 서버 주소에 프로토콜을 중복 입력하지 않았는지 확인합니다.
  • 사용자 이름, 비밀번호, 포트 번호, 원격 경로를 다시 확인합니다.
  • 서버 방화벽과 공유기의 포트 차단 여부를 확인합니다.
  • PC의 다른 클라이언트 프로그램으로 같은 계정이 접속되는지 확인합니다.

SMB

  • 공유 폴더명과 계정의 읽기 권한을 확인합니다.
  • 서버가 사용하는 SMB 버전과 인증 방식을 확인합니다.
  • 로컬 네트워크에서는 서버 이름 대신 IP 주소로 시험해 봅니다.

FTP·SFTP

  • FTP와 SFTP는 서로 다른 프로토콜이므로 선택을 정확히 합니다.
  • 기본 포트는 보통 FTP 21, SFTP 22이지만 서버 설정을 우선합니다.
  • SFTP 개인키 사용 시 키 형식과 서버 등록 상태를 확인합니다.

저장 및 공유 안내

속도·피치·EQ 편집본, 보컬 제거 결과물, 오버더빙 생성물은 앱 내부 저장소에 저장됩니다.

저장 파일 관리

  • 앱의 저장 파일 또는 파일 관리 화면에서 결과물을 확인합니다.
  • 저장 공간이 부족하면 작업이 실패할 수 있으므로 여유 공간을 확보합니다.
  • 앱 삭제 또는 앱 데이터 초기화 시 내부 저장 파일도 삭제될 수 있습니다.
  • 중요한 결과물은 공유 또는 내보내기를 통해 별도로 백업합니다.

카카오톡 등으로 공유

  1. KSRRangAudio에서 저장된 결과 파일을 선택합니다.
  2. 공유 버튼을 누릅니다.
  3. 카카오톡, 이메일, 클라우드 저장소 등 전달할 앱을 선택합니다.
  4. 상대 앱에서 수신자 또는 저장 위치를 선택해 전송합니다.
공유가 실패하는 경우 파일 크기가 상대 앱의 전송 제한을 초과할 수 있습니다. 파일을 더 작은 크기로 저장하거나 클라우드 저장소에 올린 뒤 링크를 공유하세요.

자주 묻는 질문

오디오 또는 동영상 파일이 열리지 않습니다.

파일이 손상되었거나, 해당 파일의 코덱 또는 컨테이너 형식이 기기에서 지원되지 않을 수 있습니다. 다른 플레이어에서도 파일이 정상 재생되는지 확인하고, 파일 접근 권한이 허용되어 있는지 확인하세요.

외장 저장장치나 파일 관리자에서 선택한 파일은 Android의 파일 접근 권한이 만료되면 다시 선택해야 할 수 있습니다.

속도·피치·EQ가 적용된 파일은 어디에 저장됩니까?

편집본, 보컬 제거 결과물, 오버더빙 생성물은 KSRRangAudio의 앱 내부 저장소에 저장됩니다. 앱의 파일 관리 또는 저장 결과 화면에서 확인할 수 있습니다.

앱을 삭제하거나 앱 데이터를 초기화하면 내부 저장소의 파일도 삭제될 수 있으므로 중요한 결과물은 공유 또는 내보내기 기능으로 별도 보관하세요.

저장된 파일을 카카오톡이나 다른 기기로 보낼 수 있습니까?

네. 저장된 파일을 선택한 후 공유 기능을 실행하면 카카오톡, 이메일, 클라우드 저장소 등 Android 공유 기능을 지원하는 앱으로 전달할 수 있습니다.

파일 크기가 크면 상대 앱의 전송 용량 제한으로 인해 공유가 실패할 수 있습니다. 이 경우 클라우드 저장소나 다른 파일 전송 방식을 사용하세요.

SMB 서버에 연결되지 않습니다.
  • 휴대전화와 SMB 서버가 같은 네트워크에 있는지 확인합니다.
  • 서버 주소, 공유 폴더명, 사용자 이름과 비밀번호를 확인합니다.
  • 공유 폴더에 해당 계정의 읽기 권한이 있는지 확인합니다.
  • 공유기 또는 서버 방화벽이 SMB 연결을 차단하지 않는지 확인합니다.
  • 서버가 지원하는 SMB 버전과 보안 설정을 확인합니다.
FTP 또는 SFTP 서버에 연결되지 않습니다.
  • FTP와 SFTP는 서로 다른 방식이므로 프로토콜 선택을 확인합니다.
  • 서버 주소와 포트를 확인합니다. 일반적으로 FTP는 21, SFTP는 22를 사용하지만 서버 설정에 따라 다를 수 있습니다.
  • 사용자 이름, 비밀번호 또는 개인키가 정확한지 확인합니다.
  • 모바일 네트워크나 공유기 방화벽에서 해당 포트가 차단되지 않았는지 확인합니다.
  • 서버의 접속 로그를 확인하여 인증 실패 원인을 점검합니다.
원격 파일 재생이 자주 끊깁니다.

네트워크 속도, 서버 응답 속도, Wi-Fi 신호, 파일 비트레이트에 따라 끊김이 발생할 수 있습니다. 5GHz Wi-Fi 또는 안정적인 유선 서버 연결을 사용하고, 백그라운드 다운로드나 다른 네트워크 작업을 줄여 보세요.

보컬 제거에 시간이 오래 걸립니다.

보컬 제거는 AI 연산을 사용하는 고부하 작업입니다. 파일 길이, 기기 성능, 배터리 절약 설정, 발열 상태에 따라 처리 시간이 달라질 수 있습니다.

처리 중에는 앱을 종료하지 말고, 배터리 잔량이 충분한 상태에서 작업하는 것을 권장합니다.

오버더빙에서 마이크 소리가 녹음되지 않습니다.
  • Android 설정에서 KSRRangAudio의 마이크 권한을 허용합니다.
  • 다른 녹음 앱이나 통화 앱이 마이크를 사용 중인지 확인합니다.
  • Bluetooth 헤드셋 연결 시 입력 마이크가 달라질 수 있습니다.
  • 기기의 마이크가 다른 녹음 앱에서 정상 작동하는지 확인합니다.
백그라운드 재생이 중지됩니다.

제조사 배터리 절약 기능이 KSRRangAudio의 백그라운드 동작을 제한할 수 있습니다. Android 설정의 배터리 메뉴에서 KSRRangAudio를 제한 없음 또는 최적화 제외로 설정하고, 알림 권한을 허용하세요.

앱 삭제 후 저장 파일이 사라졌습니다.

앱 내부 저장소에 있는 파일은 앱 삭제 또는 앱 데이터 초기화 시 함께 삭제될 수 있습니다. 중요한 파일은 삭제 전에 공유, 내보내기 또는 다른 저장소로 복사해야 합니다.
