KSRAudio Support

Help with playback, editing, vocal removal, overdubbing, SMB/FTP/SFTP connections, saving, and sharing.

Email support

Before contacting support

  1. Update KSRAudio to the latest version.
  2. Fully close and reopen the app.
  3. Check free storage space and the network connection.
  4. Check media, microphone, and notification permissions in Android Settings.
  5. For remote servers, verify that the same account works from another app or computer.

Keep your originals: back up important source files before editing, vocal removal, or overdubbing.

Playback troubleshooting

  1. Check whether the file plays in another player.
  2. Confirm that it is complete and not damaged.
  3. Check KSRAudio's audio and video access permission.
  4. Re-select files obtained through external storage or a file-provider app.
  5. For remote media, check Wi-Fi signal and server response.
  6. Close other apps before playing high-resolution or high-bitrate media.

Files with the same extension can use different codecs. For a file-specific issue, include the extension, codecs, and approximate size in your report.

SMB, FTP, and SFTP connections

Check the server address, port, username, authentication details, remote path, firewall, and network reachability. FTP and SFTP are different protocols; select the correct one. Typical ports are FTP 21 and SFTP 22, but your server configuration takes priority.

  • For SMB, check the share name, account read permission, SMB version, and authentication method.
  • On a local network, try the server IP address instead of its name.
  • For SFTP private keys, check the key format and server registration.

Never email passwords, private keys, or complete connection URLs.

Saving and sharing

Speed/pitch/EQ edits, vocal-removal results, and overdubs are stored in app-internal storage. App uninstall or data reset may delete them, so export important results.

  1. Select a saved result in KSRAudio.
  2. Tap Share.
  3. Choose email, messaging, cloud storage, or another destination.
  4. Select the recipient or save location in that app.

If sharing fails, the destination may impose a size limit. Create a smaller file or upload it to cloud storage and share a link.

Frequently asked questions

Why won't a media file open?

It may be damaged, use an unsupported codec or container, or lack a valid Android access grant. Test it in another player, check permissions, and re-select it if necessary.

Where are edited files stored?

Edits, vocal-removal results, and overdubs are kept in KSRAudio's internal storage. Export important files before uninstalling or clearing app data.

Why does remote playback stop?

Network speed, server response, Wi-Fi signal, and media bitrate can cause interruptions. Use a stable connection and reduce other network traffic.

Why does vocal removal take a long time?

It is compute intensive. Duration depends on file length, device performance, battery-saving settings, and temperature. Keep the app open and ensure sufficient battery.

Why is my microphone not recorded?

Allow microphone permission, close other apps using the microphone, check the selected Bluetooth input, and test the microphone in another recording app.

Why does background playback stop?

Device battery management may restrict the app. Set KSRAudio to unrestricted or exclude it from battery optimization, and allow notifications.

What to include in an email

  • KSRAudio app version
  • Phone manufacturer and model
  • Android version
  • Affected feature and exact reproduction steps
  • Error message or screenshot
  • File type and approximate size
  • For remote connections, the protocol and port—but no credentials
